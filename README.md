# A-share Quant

个人 A 股量化研究与选股项目，使用 Python + AKShare 获取公开市场数据。

> 当前阶段：**Phase 2：全市场快照、板块概览和趋势回调指标初筛**。每日自动定时运行尚未启用；先通过手动 workflow 验证数据源覆盖、限流情况和指标正确性。

## 已实现功能

### 单股连通性测试
- 获取指定股票实时盘口行情：stock_bid_ask_em
- 获取指定股票前复权日线：stock_zh_a_hist_em
- 工作流：AKShare connectivity smoke test

### 全市场扫描（手动测试）
- 获取沪深京 A 股实时行情快照，优先使用 stock_zh_a_spot_em；触发东方财富限流时切换新浪 stock_zh_a_spot
- 统计上涨/下跌家数、市场成交额和成交额超过 1 亿元的股票数量
- 获取行业板块、概念板块涨跌幅概览；东方财富板块接口不可用时，使用新浪 stock_sector_spot 作为备用来源
- 对满足流动性条件的股票建立历史 K 线请求池，默认最多请求 80 只，逐只请求并限速
- 计算 MA5、MA10、MA20、近5/20/60日涨幅、近10日上涨波段、近5日高点回撤、成交量收缩比、20日平均成交额和支撑距离
- 将日线初筛结果标记为 B/C 档；没有分钟线确认时绝不标记为 A 档或可买入
- 输出 data/market_scan.json 和 data/candidates.csv，作为 GitHub Actions Artifact 保存30天

## 运行全市场扫描
1. 打开仓库 Actions 页面。
2. 选择 A-share full-market scan。
3. 点击 Run workflow。
4. 初次测试建议保留默认值：max_history_stocks=80、min_amount_cny=100000000、delay_seconds=1.2。
5. 等待运行结束，在 Artifacts 下载 a-share-market-scan。

本地运行需要 Python 3.11 环境：
- python -m pip install -r requirements.txt
- python -m unittest discover -s tests -v
- python -m src.market_scan --max-history-stocks 80 --min-amount-cny 100000000 --delay-seconds 1.2

## 数据质量与限制
- 全市场快照与详细历史 K 线分开处理：先获取全市场快照，再按可用的60日涨幅字段和当日成交额排序，挑选最多80只股票获取详细日线。当日成交额仅用于排序、缩小历史请求池，不再作为1亿元硬性剔除条件；真正的近20日平均成交额门槛由历史日K线计算。这不是对全市场每一只股票都计算了完整技术指标；覆盖数量会写入 JSON。
- AKShare 上游公开接口可能限流、变更字段或暂时不可用。东方财富行情接口触发限流后，本次运行会跳过后续东方财富行情请求，历史日线优先切换腾讯，板块数据切换新浪；不会在已限流的来源上反复重试。数据不完整会在结果中体现。
- spot_retrieved_at 是程序采集时间，不是交易所逐笔报价时间。
- MA和成交量指标只使用当前交易日前已完成的日K线；当前价格/涨幅来自实时快照，避免把未收盘日K线混入均线。
- 本阶段尚未实现14:30分钟线确认、财务公告核验、历史推荐复盘和自动通知；所有候选的 buyable 均为 false，不输出虚构买入价和止盈价。
- 全市场快照若不足1000只有效股票，将拒绝作为完整市场数据使用。
- 若行业或概念板块任一数据源均不可用，JSON中的status会标记为partial，而不是把缺失板块数据视为完整成功。
- 新浪实时行情不提供与东方财富相同的60日涨跌幅字段；本项目会从已获取的历史K线补算60个交易日涨幅。

### 趋势过滤补充

- 强势趋势判断要求60个交易日涨幅为正、20个交易日涨幅为正、MA20斜率为正，且现价不明显跌破MA20；缺少60日历史数据时不认定为趋势合格。
- 若新浪行情源未提供60日涨幅字段，结果会明确显示 `spot_60d_available_count=0`，并使用逐只获取的历史K线计算 `history_positive_60d`，避免把缺失字段误报成全市场60日上涨家数为0。


### 本轮筛选逻辑修正

- 当日实时成交额只用于确定有限历史行情请求池的优先顺序，不再用来替代近20日平均成交额，也不在早盘用1亿元阈值提前排除股票。
- 近20日平均成交额是否达到1亿元，仍以已完成日K线计算结果为准。
- B档定义为：60日/20日趋势、MA20斜率和流动性等基础门槛通过，且上涨波段、回调、缩量、支撑四项结构信号至少满足两项并达到评分门槛；没有分钟线确认时仍不产生A档或买入信号。
